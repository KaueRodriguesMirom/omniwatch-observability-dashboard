Título: OmniWatch - IT Infrastructure & Observability Dashboard.
 
Descrição: "Projeto criado para simular o monitoramento em tempo real de infraestrutura de TI, redes e microsserviços. Como analista de sistemas, entendo a importância de acompanhar a saúde dos serviços (SLAs, latência, uptime). Este dashboard consome dados simulados para representar alertas e saúde de nós de rede."
 
Tecnologias: React, Tailwind CSS, Componentização.
